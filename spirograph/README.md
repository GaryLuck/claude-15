# Spirograph

An interactive spirograph drawing tool built as a single, self-contained HTML file.

## What is a Spirograph?

A spirograph is a geometric drawing device that produces mathematical roulette curves — the beautiful, looping patterns formed by tracing a point on a small circle rolling inside (or outside) a larger circle. This project recreates that experience in the browser using HTML5 Canvas.

## Features

- Interactive controls for the inner and outer circle radii
- Adjustable pen offset distance
- Live canvas rendering as the curve is drawn
- Colour picker and line-width control
- Animate / step-through drawing mode
- Save / download the canvas as a PNG image
- No dependencies — runs entirely in a single HTML file

## Usage

Open `spirograph.html` directly in any modern browser. No server or build step is needed.
